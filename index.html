How I check AI agents

Agents should not be able to grade their own homework.

If an AI agent can chase its own score, the score stops meaning anything. That is Goodhart's law: when a measure becomes a target, it stops being a good measure. Below is how I keep agents apart from the code that scores them, and how I test the product every night. It is part of Shayke, an applied learning project I built with AI coding agents in my own time. It has no customers.

Keeping agents apart from their grader
